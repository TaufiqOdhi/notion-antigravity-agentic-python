# Notion to Antigravity CLI Automator

This repository contains an automation script to periodically pull tasks from a Notion database and pass them to the Antigravity CLI (`agy`) for non-interactive execution. 

## Features
- **Fetch Tasks:** Fetches database entries with status `To Do` or `In Progress`.
- **Status Tracking:** Automatically marks a task as `In Progress` when execution starts, and `In Review` when it successfully completes.
- **Dedicated Workspace:** Automatically creates and mounts a `src/` directory where all the agent's work, code, and project files are safely generated.
- **Headless Execution:** Invokes `agy` using print mode (`agy -p`) with auto-approved permissions (`--dangerously-skip-permissions`).
- **Quota Guardrail:** Prompts `agy` to monitor token limits, stop early if necessary, and document current progress (`progress_handoff.md`) for seamless continuation by local models (e.g., Hermes in LM Studio).

## Setup Instructions

### 1. Requirements
Ensure you have the required Python library:
```bash
pip install requests
```

### 2. Environment Configuration
Create a `.env` file in the root of the workspace containing your Notion credentials.

```env
NOTION_TOKEN=your_notion_integration_token
NOTION_URL=your_notion_database_url
NOTION_VERSION=2022-06-28
```

#### Fields:
- **`NOTION_TOKEN`**: The secret token generated by your Notion integration.
- **`NOTION_URL`**: The full URL to your Notion database page. The script will automatically parse the database ID from this URL path.
- **`NOTION_VERSION`**: The Notion API version to target (defaults to `2022-06-28`).

### 3. Database Schema Requirements
Ensure your Notion database uses a **Select** property named **Status** with the following exact options:
- `To Do`
- `In Progress`
- `In Review`

### 4. Run Manually
To test that your Notion configuration and the script are working correctly:
```bash
python3 notion_agy_automator.py
```

### 5. Cronjob Setup (Periodic Automation)
To run this script automatically in the background, you can register it as a cronjob.

1. Open your crontab configuration:
   ```bash
   crontab -e
   ```
2. Add a line to run the script periodically (e.g., every hour at minute 0):
   ```bash
   0 * * * * cd /workspace && /usr/bin/python3 /workspace/notion_agy_automator.py >> /workspace/automator.log 2>&1
   ```
